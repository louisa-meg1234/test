Points to check before handoff

  1. English mixes clock formats: the period headers use 12-hour times, but sleep onset, wake-up and nap times stay on a 24-hour clock (22:10, 15:11). Pick one format for the whole panel.
  2. Nap dates use YYYY/MM/DD (2026/09/27) while period headers use month names (27 Sept. 2026). Pick one date format for the panel.

Resolved: “Bedtime” is now “Sleep onset time”, “Total wake time” is now “Total awakening duration”, “13:18pm” is now “1:18pm”, period dates use month names, so day/month order is no longer ambiguous, English uses lowercase “pm” throughout, and nap dates now fall inside their period (naps listed in time order).
